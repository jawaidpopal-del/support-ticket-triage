# Session logs

Save the full transcript of each blind-handoff session here, as plain text or markdown:

```
logs/handoff-1.md     # the fresh session that implemented spec-v1
logs/handoff-2.md     # the fresh session that implemented spec-v2
```

**Claude Code:** select the whole terminal transcript after the session ends and paste it
into the file. **Copilot / Cursor:** use the chat's copy or export action, or select the
thread and paste it. Either way the log must show the *first message* you sent — the
grader needs to see that it was the one-line handoff instruction pointing at your
specification, with nothing before it.
