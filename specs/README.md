# Specifications

One feature, one file. Name it after the feature.

```
specs/filtered-summary.md
specs/ticket-triage.md
```

For the assignment you will end up with two: `spec-v1.md` and `spec-v2.md`, so both
rounds of the blind handoff can be compared.

The template is `feature-spec-template.md`, in Canvas. The eight sections and the
unhappy paths this repository actually has are in
`.claude/skills/how-to-write-a-spec/SKILL.md`.
